# My Annual Review

A personal, interactive workbook for the yearly review, built around the twelve-step Annual Review wheel.

- Single file: open `index.html` in a browser. No build step.
- Answers save in the browser (localStorage and IndexedDB) on this device.
- **Versions** button: save named snapshots, restore them, and download or import a JSON backup file.
- Inside Claude it can also save to the account; outside Claude it works on local storage only.
